# 🎮 JokeyPÔ — Premium Edition

Um jogo de **Pedra, Papel e Tesoura** desenvolvido com HTML, CSS e JavaScript, com uma interface moderna, animações e diferentes níveis de dificuldade.

## 🚀 Demonstração

[**Jogue JokeyPÔ Premium Edition**](https://leonardolkcnova-cloud.github.io/jokeypo-premium/)

## ✨ Funcionalidades

- 🪨 Pedra, Papel e Tesoura
- 🤖 Modos de dificuldade: Fácil, Médio e Difícil
- 🏆 Sistema de pontuação em partidas melhor de cinco
- 📊 Estatísticas de desempenho
- 📜 Histórico de partidas
- 💾 Armazenamento de dados no navegador
- 🔊 Efeitos sonoros
- 🎨 Animações e interface premium
- 📱 Layout responsivo para diferentes dispositivos

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Audio API

## 📂 Estrutura do projeto

## 🎯 Como jogar

1. Acesse o jogo pelo link da demonstração.
2. Escolha o nível de dificuldade.
3. Selecione Pedra, Papel ou Tesoura.
4. Jogue contra o computador e tente vencer a partida!

## 💻 Como executar localmente

1. Clone este repositório:

```bash
git clone https://github.com/leonardolkcnova-cloud/jokeypo-premium.git
```

2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` com a extensão Live Server.
